# 彩虹战机大冒险 · Rainbow Jet Adventure

一款面向 **4—7 岁儿童**的竖版飞行射击小游戏（HTML5 Canvas + 原生 JavaScript）。
玩法参考经典街机纵向卷轴射击，但难度、弹幕密度与操作方式完全为低龄儿童重新设计。

> 打开 [`index.html`](index.html) 即可游玩 —— 单文件、零依赖、离线可用。

## 玩法

- **按住屏幕拖动**小飞机（手指可以稍微离开机身，不会挡住主角），或使用 **方向键 / WASD**
- 子弹**自动连发**，不需要点击射击
- 收集星星与道具，飞过 5 个主题天空

## 特色

| 系统 | 说明 |
|---|---|
| 5 个关卡 | 彩虹天空 → 糖果星球 → 海底探险 → 太空冒险 → 彩虹城堡，各有专属视差背景与 BOSS |
| 武器升级 | 蓝色双发 / 彩虹三向散弹 / 闪电贯穿激光 / 星星五向弹幕，升级持续 20 秒 |
| 道具 | 护盾（无敌 6 秒）、爱心（上限 5 颗） |
| 儿童保护 | 开局 5 心、受伤 3 秒无敌闪烁、敌弹稀疏且留出躲避通道、爱心耗尽可原地满血续关且不丢进度 |
| 轻量教育 | 收集星星时偶尔跳出 1—10 的数字与鼓励语，不打断战斗 |
| 音效 | Web Audio API 实时合成，无外部音频文件，可一键静音 |
| 适配 | 竖屏 9:16，自适应手机 / 平板 / 桌面，支持 DPR 与安全区域 |

## 本地运行

```bash
# 方式一：直接双击 index.html

# 方式二：起一个本地服务（便于手机 / 平板同局域网访问）
python3 -m http.server 8000
# 然后打开 http://localhost:8000
```

## 源码结构

```
index.html          # 成品：内联了全部 CSS 与 JS，单文件可分发
src/
  index.html        # 开发版（外链 css / js）
  style.css
  game.js           # 全部游戏逻辑与 Canvas 矢量绘制（约 3200 行）
build.js            # 把 src 内联打包成根目录 index.html
```

修改源码后重新打包：

```bash
node build.js
```

## 技术说明

- 逻辑分辨率固定 `540 × 960`，按窗口等比缩放，backing store 乘设备像素比（上限 2.5）保证清晰度
- 全部美术为 Canvas 矢量绘制（渐变、贝塞尔曲线、合成路径），无任何图片资源
- 粒子系统：爆炸星星、彩色泡泡、闪亮碎片、彩虹拖尾，数量上限 340 以保证帧率
- 状态机：`title / help / tutorial / playing / paused / bossdown / clear / continue / win`
- 失焦、切后台、窗口尺寸变化自动暂停，避免操作中断后卡死

浏览器要求：支持 Pointer Events 与 Web Audio 的现代浏览器（Chrome / Edge / Safari / Firefox）。
